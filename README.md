# Eventify

A full-stack MERN event management and ticket booking platform.

## Project Overview

Eventify allows customers to discover events, book tickets, and manage their bookings. Event organizers can create and manage events, while administrators oversee the platform.

## User Roles

- Customer
- Event Organizer
- Admin

## Planned Features

- User authentication and role-based access
- Event discovery, search, and filtering
- Event creation and management
- Ticket booking and payment integration
- QR-based digital tickets
- Booking history and cancellation management
- Organizer dashboard and sales analytics
- Admin dashboard and event moderation

## Technology Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- Tailwind CSS
- Redux Toolkit
